# friends-of-steve-rambo.github.io

Статический сайт игровых серверов GitHub Pages. Главная страница — `index.html`, страница игры — `game.html?game=<id>`.

Все данные игр, настроек и сборов по месяцам лежат в `js/data.js` в массиве `window.GAMES`. Чтобы обновить информацию, добавить месяц или новую игру, отредактируйте нужный объект в этом массиве — карточки, навигация и страницы обновятся автоматически.
